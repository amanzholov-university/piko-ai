# Piko AI — дашборд курсов

Личная (непубличная) страница для управления ИИ-курсами:

1. ИИ для старшего поколения
2. ИИ для маркетинга, SMM и медиа
3. ИИ для педагогов
4. ИИ для IT-студентов
5. ИИ-агенты

Один файл `index.html`, без сборки — просто открыть в браузере.
Отметки модулей, статусы и заметки сохраняются в localStorage браузера.
Программы курсов редактируются в массиве `COURSES` внутри `index.html`.

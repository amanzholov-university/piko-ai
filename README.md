# Piko AI — студия курсов

Личная студия для разработки ИИ-курсов и режим показа для слушателей.

Курсы: старшее поколение · маркетинг, SMM и медиа · педагоги · IT-студенты · ИИ-агенты.

## Как устроено

- `index.html` — вся страница (студия + режим показа).
- `content.json` — содержимое курсов: описания, уроки и блоки уроков
  (текст, презентация, видео, задание, ссылка, файл).

Рабочая версия опубликована как приватный артефакт на claude.ai: там работают
загрузка файлов, сохранение (`content.json` переписывается кнопкой «Сохранить»)
и приватные заметки/прогресс владельца.

- **Студия** видна только владельцу/редакторам.
- **Режим показа** видят все остальные, кому открыт доступ к ссылке,
  а владелец включает его кнопкой «Режим показа».

Локально (открыть `index.html` через веб-сервер) студия работает без загрузки
файлов и без сохранения в облако.
